## 一、核心原则（必须遵守）

### 1.1 环境隔离原则

| 环境 | 数据来源 | Mock使用 | 语言要求 |
|------|----------|----------|----------|
| **正常环境** | 真实API（高德、Tavily、MiMo） | ❌ 禁止 | 必须中文 |
| **测试环境** | Mock数据 | ✅ 允许 | 中文/英文均可 |

### 1.2 数据真实性原则

**✅ 正确做法：**
- 使用高德API获取真实POI数据
- 使用MiMo进行意图解析
- 使用Tavily进行联网核验
- 所有返回内容必须是中文
- 失败时返回中文阻断提示

**❌ 错误做法：**
- 使用SeedData中的英文假数据
- 使用关键词匹配代替LLM
- 返回英文分享消息
- 失败时静默降级到Mock
- 使用硬编码的假POI名称

### 1.3 失败处理原则

**核心理念：宁可阻断，不可造假**

当真实服务不可用或候选地点不足时：
- ❌ 不编造方案
- ❌ 不使用SeedData
- ✅ 返回中文阻断提示
- ✅ 记录trace信息

### 步骤5：路线 Agent → 高德距离/路线接口

**职责：** 调用高德路线规划，计算真实距离和耗时

**高德路线API调用：**
```python
def get_route(origin_lng, origin_lat, dest_lng, dest_lat, key):
    url = "https://restapi.amap.com/v3/direction/walking"
    params = {
        "key": key,
        "origin": f"{origin_lng},{origin_lat}",
        "destination": f"{dest_lng},{dest_lat}"
    }
    response = requests.get(url, params=params)
    route = response.json()["route"]
    return {
        "distance": int(route["paths"][0]["distance"]),  # 米
        "duration": int(route["paths"][0]["duration"])   # 秒
    }
```

**路线优化逻辑：**
```python
def optimize_route(pois, intent):
    total_time = 0
    route = []
    
    for i in range(len(pois) - 1):
        segment = get_route(pois[i], pois[i+1])
        total_time += segment["duration"] / 60  # 转换为分钟
        route.append(segment)
    
    # 检查是否在4-6小时内
    min_hours = intent["time_window"]["min_hours"] * 60
    max_hours = intent["time_window"]["max_hours"] * 60
    
    if total_time < min_hours:
        # 需要延长活动时间
        extend_extra_activity(pois, min_hours - total_time)
    elif total_time > max_hours:
        # 需要缩短活动时间
        shorten_optional_activity(pois, total_time - max_hours)
    
    return route
```

### 步骤7：中文校验器 + 防编造校验器

**职责：** 检查输出是否合规，失败则阻断

**中文校验器：**
```python
def validate_chinese(text):
    """检查文本是否包含英文"""
    import re
    # 检查是否包含英文字母（排除常见英文缩写如API、WiFi等）
    english_pattern = r'[a-zA-Z]{3,}'  # 至少3个连续英文字母
    exceptions = ['API', 'WiFi', 'GPS', 'QR', 'ID']
    
    matches = re.findall(english_pattern, text)
    for match in matches:
        if match not in exceptions:
            return False, f"包含英文: {match}"
    
    return True, None
```

**防编造校验器：**
```python
def validate_no_fabrication(plan, real_pois):
    """检查方案中的地点是否来自真实POI"""
    real_poi_names = {poi["name"] for poi in real_pois}
    
    for item in plan["timeline"]:
        if item["place"] not in real_poi_names:
            return False, f"地点不在真实POI中: {item['place']}"
    
    return True, None
```

**校验失败处理：**
```python
def validate_plan(plan, real_pois):
    # 中文校验
    is_chinese, error = validate_chinese(json.dumps(plan, ensure_ascii=False))
    if not is_chinese:
        return {
            "error": f"抱歉，方案包含非中文内容: {error}",
            "status": "blocked"
        }
    
    # 防编造校验
    is_valid, error = validate_no_fabrication(plan, real_pois)
    if not is_valid:
        return {
            "error": f"抱歉，方案包含非真实地点: {error}",
            "status": "blocked"
        }
    
    return {"status": "valid"}
```

## 三、Agent架构设计

### 3.1 设计原则

**v1使用1个LLM（MiMo），多个Agent角色共享**

- 不是每个Agent一个模型
- 而是专业化分工 + 共享LLM
- 每个Agent有独立的职责和工具
- Agent间通过消息传递协作

### 3.2 Agent列表

| Agent | 职责 | 工具 | 输入 | 输出 |
|-------|------|------|------|------|
| IntentParserAgent | 意图解析 | MiMo API | 用户自然语言 | 结构化JSON |
| SearchVerifierAgent | 联网核验 | Tavily API | 地点+场景 | 实时信息 |
| POISearchAgent | POI搜索 | 高德API | 关键词+范围 | 真实POI列表 |
| RouteOptimizerAgent | 路线优化 | 高德路线API | POI列表 | 最优路线 |
| PlanGeneratorAgent | 方案生成 | MiMo API | 真实POI+约束 | Top-3方案 |
| ExceptionRecoveryAgent | 异常恢复 | MiMo API | 异常类型 | 替代方案 |

### 3.3 Agent协作流程

```
用户输入
    ↓
IntentParserAgent → 结构化意图
    ↓
┌─────────────────────────────────────┐
│ 并行执行                            │
├─────────────────────────────────────┤
│ SearchVerifierAgent → 联网核验结果  │
│ POISearchAgent → 真实POI列表        │
└─────────────────────────────────────┘
    ↓
RouteOptimizerAgent → 最优路线
    ↓
PlanGeneratorAgent → Top-3方案
    ↓
中文校验器 + 防编造校验器
    ↓
用户确认
    ↓
执行（Mock）
```

## 五、失败策略

### 5.1 失败场景处理

| 失败场景 | 处理方式 | 返回内容 |
|----------|----------|----------|
| MiMo API调用失败 | 降级到关键词匹配 | 使用简化意图继续 |
| 高德API失败/Key缺失 | 返回中文阻断提示 | "抱歉，暂时无法获取地点信息，请稍后重试" |
| Tavily API失败 | 跳过联网核验 | 继续流程，trace记录 |
| POI结果为空 | 返回中文阻断提示 | "抱歉，未找到符合条件的地点" |
| LLM输出不合规 | 返回中文阻断提示 | "抱歉，方案生成失败，请重试" |
| 餐厅无座位 | 自动替换餐厅 | 返回替代餐厅 |
| 活动无票 | 自动替换活动 | 返回替代活动 |
| 行程超时 | 缩短可选活动 | 返回调整后方案 |
